Odds

A collection of small, odd VCV Rack modules by Haer. Version 2.0.0, MIT licence. It currently holds one module: Minimal Nation.

Minimal Nation

One big knob, one input, one output. The signal passes straight through, on every polyphony channel, and the knob does nothing. It is there to look at.

The knob is a real parameter (0 to 10, default 5, named "Nothing") and it is saved with the patch, but nothing in the code reads it. Turning it has no effect on the sound.

Panel

12 HP, white panel. The knob uses Haer's knob design 241: a fixed shaded ball inside a black ring, with a black bar and a red dot that turn with the knob (about 300 degrees of travel).

ItemWhat it is
Big knobDoes nothing. Range 0 to 10, default 5.
In jackAny signal, mono or polyphonic.
Out jackAn exact copy of the input, with the same number of channels.

When the module is bypassed, the input is wired to the output as well, so it is transparent either way.

Using it

  • Patch a cable into In and take Out to the next module. Nothing about the signal changes.
  • It works for audio, CV and gates, since the voltage is copied untouched.
  • Because there is no processing, it adds no sound and no noise.

Patch ideas

  • A signal tidier: use it as a visible junction in a patch, with one cable in and one out, where the knob gives your eye something to rest on.
  • A decoy knob: leave it in a rack as a placebo control. Turn it while someone watches the sound not change.
  • A polyphony check: put it in a poly cable run to confirm that all the channels come through unchanged (it keeps every channel).

Building

Every push builds the plugin for Apple Silicon Macs in GitHub Actions. Pushes to main publish to the "latest" release and branch pushes to "preview". Source: github.com/hardyfinn/Odds.
