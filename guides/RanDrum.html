Randrum

A VCV Rack 2 drum sample player that rolls dice on every hit.

Load a folder of WAV or AIFF files and send it triggers. Each hit picks a sample and a pitch, decay, start point, level, pan and direction, inside ranges you set with the knobs. LOOP and MUTATE turn those dice rolls into a pattern that repeats and slowly rewrites itself, so a random part can sit still long enough to groove and then drift somewhere new.

Getting sound out

  1. Right-click the module and choose Load folder..., or drag a folder (or any sample inside it) from Finder onto the screen. Subfolders are included, so you can drop a whole sample library.
  2. Patch a clock or gate sequencer into TRIG, and OUT L into your mixer.
  3. Turn SPREAD down to narrow which samples it picks from, and use SAMPLE to move that window through the folder.

One Randrum plays one part. Use one for hats, another for perc, another for kicks, each with its own folder.

How the dice work

Every trigger uses a set of eight dice: which sample, pitch, decay, start, level, pan, reverse, and whether the hit plays at all. The knobs decide how far each die may push things. Dice and knobs are kept apart, so turning a RND knob rescales the same rolls rather than rolling new ones. A locked pattern stays the same pattern while you make it wilder or tamer.

  • LOOP (small knob under MUTATE): 1 to 16 hits. The dice for each hit are kept in a ring of that length, so the pattern repeats. Fully counter-clockwise is free: new dice every hit.
  • MUTATE: on every hit, the chance that each die is rolled again. At zero the loop is locked. Around 5 to 15% it changes a little each time round. Fully clockwise is pure noise.
  • VARIETY: how many different samples the loop uses, from 1 up to all (fully clockwise, the default). At 3, an 8-step loop uses three sounds, each repeated, and a repeat never lands next to itself (around the loop end too), so you get A B A C B C A B rather than A A B B. Which sounds and in what order are part of the dice, so MUTATE changes them slowly and REROLL picks new ones. It works in rnd pick mode. With LOOP on free, each hit picks one of the VARIETY sounds, never the same twice in a row.
  • REROLL (button or gate): roll the whole loop again in one go.
  • RESET: the next hit is the first of the loop. Patch the bar or pattern reset here to keep the loop lined up with your other parts.

Patterns: MEMORY, morph and ratchets

The column on the right (added in version 2.3, which made the module 28 HP wide):

  • A, B, C, D: four pattern memories. Press SAVE (it lights), then a letter, to store the loop's dice there. A dim light means the slot holds a pattern; a bright one is the pattern the loop came from. The screen shows LOOP A, or LOOP A~ once MUTATE has changed it.
  • jump / morph switch, for what pressing a letter does:
    • jump: the loop switches to that pattern at the start of the next loop, so it stays in time. The letter blinks and the screen says B next until then. Right-click > JUMP changes pattern straight away switches immediately.
    • morph: the letter becomes a target. MUTATE now copies the target's dice instead of rolling new ones, so the loop drifts toward the target one die at a time, at a speed set by MUTATE. The screen shows the progress (> B 63%). Press the letter again to go back to random mutation.
  • PAT CV: 0 to 10 V picks A, B, C or D (2.5 V each). Use it to sequence song sections from Ableton or a slow stepped CV.
  • RATCHET (plus CV): the chance that a step plays a roll of 2, 3 or 4 quick repeats instead of one hit. Repeats are spaced evenly across the time to the next trigger, each a little quieter. Which steps roll is part of the dice, so rolls repeat with the loop. They show as a yellow ring around the step and x3 on the second line. Every repeat also fires HIT.

Saved patterns are kept in the patch. They hold the dice, not the knob settings, so a pattern can still be made tamer or wilder with the RND knobs.

The screen

  • Top line: folder name and file count, then the PICK mode.
  • Second line: the file that just played (orange, or purple when skipped), then its pitch, decay, level, pan and REV.
  • Waveform: the last file. The orange line is the start point, the yellow curve is the decay, white lines are playheads.
  • Strip: one cell per file. Teal cells are the SPREAD window; orange is the one that played.
  • LOOP ring: one dot per step. Filled dots will play at the current CHANCE, hollow ones will be skipped, bigger dots are louder. Orange is the step that just played. The sound for each step is shown as a letter around the ring.

Right-click menu

  • Include subfolders (on by default).
  • Load folder..., Next folder, Previous folder, Folders next to this one (handy when kits sit side by side in one parent folder).
  • Reload folder, after adding files.
  • Random pitch in whole semitones, which makes PITCH RND melodic.
  • Re-roll the whole loop.
  • JUMP changes pattern straight away.

Sample files

  • The folder path and the loop's dice are saved with the patch. The samples are not copied into it, so keep the folder where it is.
  • Up to 1024 WAV or AIFF files per folder, counting subfolders (8, 16, 24 or 32-bit PCM, or 32 or 64-bit float, any sample rate, mono or stereo), up to 30 seconds each. Files are ordered by path, so subfolders stay together.
  • If a folder won't load, the screen says why. "macOS blocks Rack" means Rack needs permission for that location: System Settings > Privacy & Security > Files and Folders (or Full Disk Access) > VCV Rack 2. Rack's log.txt lists every file that couldn't be read.

Patch ideas

  1. A groove that drifts. Set LOOP to 8, MUTATE to about 10%, VARIETY to 3. Save the loop to A when it sounds good, and let the rest wander.
  2. Sections from a CV. Save four patterns to A to D, then feed a slow stepped CV into PAT CV (0 to 10 V, 2.5 V each) to switch song sections.
  3. Morph between two beats. Save two patterns, set the switch to morph, press a letter and raise MUTATE slowly. The loop drifts toward the target one die at a time.
  4. Call and response. Patch the SKIP output of one Randrum into the TRIG of another: the second plays when the first doesn't.
  5. Sidechain. Use ENV from a kick Randrum to duck a pad or open a filter on every hit.
  6. Hat rolls. Raise RATCHET on a hat part, so some steps roll 2 to 4 quick repeats that repeat with the loop.
