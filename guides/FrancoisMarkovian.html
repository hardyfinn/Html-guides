The four modules

ModuleIn one line
Francois MarkovianA Markov jump trigger sequencer: one playhead hops around an 8-step pattern of six trigger tracks (A to F), using a jump matrix you set by hand.
InterlockA trigger processor in which tracks influence each other: a hit on one track can hold back or add hits on another.
GovernorMeasures how busy and how varied the triggers are and outputs CVs that steer them towards your targets.
RewriteGrows each track's one-bar pattern by its own rules every few bars, so the groove keeps moving without going random.

All four can be used on their own, or chained with three kinds of poly cable (TRIG, ACT, STATE). Put one shared clock and reset into every module.

Francois Markovian

One playhead walks an 8-step pattern with six trigger tracks, A to F. On every clock pulse it picks its next step from a hand-set jump matrix, then each track rolls its own chance for the step it lands on. The pattern stays recognisable but gets reshuffled, like a drummer skipping around the bar.

The jump matrix (left)

Each row is the step the playhead is on (FROM), and each column is a step it can go to (TO). Every cell shows its chance as a number and a bar, and each row always adds up to 100.

  • Drag a cell up or down to set its chance. The rest of the row rescales to make room and keeps its own balance: with 30 / 70 in a row, dragging a third cell to 50 leaves 15 / 35 / 50. Hold Shift for fine control.
  • Double-click a cell to switch it between 0 and 100.
  • Lowering a row's only cell spreads the rest evenly over the other cells.
  • A new module plays straight (each step goes to the next).
  • The diagonal (a step going to itself) gives stutters and rolls.
  • An empty row falls back to the next step, shown as a small outline.
  • The lighter row is where the playhead is now, and the white outline shows the jump it just took.

Trigger chances (right)

Each of the 6 x 8 cells is the chance (0 to 100) that the track fires when the playhead lands on that step. Drag it up or down, or double-click it for 0 / 100. The playhead's column is lighter, and a cell flashes when it fires. A new module starts with A on step 1 and B on step 5, both at 100.

Snapshots X and Y, and Evolve

There are two snapshots, each with its own matrix and trigger chances. The EDIT X / Y switch chooses which one the grids show and edit. A white line in a cell marks the other snapshot's value there.

EVOLVE (knob plus CV, 0 to 10 V adds 0 to 100%) blends every matrix cell and every trigger chance from X to Y. A trigger at 0 in X and 100 in Y fires half the time at the halfway point. The white tick under the X / Y switch shows where Evolve is.

Freeze

The FREEZE button (toggle) or GATE input (freezes while high) loops the last 8 steps exactly as they were played, steps and triggers, dice and all. Release it and the playhead carries on from where it is. Reset while frozen restarts the loop from its start.

Clock divider

DIV (1, 2, 4, 8, 16) and OFFSET (0, 1, 2, 4 pulses) set the DIV output: a trigger on every Nth input clock, counted from Reset and shifted later by the offset. The readout shows both, e.g. /4 +2 fires on clocks 3, 7, 11 and so on. It follows the input clock, not the jumping playhead, so it stays on the grid for syncing other gear.

Mutes

Click a track's letter (left of the trigger grid) to mute it: the letter turns into a dark M and its row dims. A muted track still rolls its dice, so it comes back in step when you unmute it. Mutes go out on ACT, so Interlock, Rewrite and Governor all know the track is off.

Right-click menu

  • Straight (step by step): reset the matrix of X, Y or both.
  • Randomise (nudge): small, controlled changes to the jump matrix of X or Y. Gentle moves 1 to 3 cells, Wild 1 to 5, each by 10 to 50 points; touched rows rescale to 100 like a drag. Press again to nudge further.
  • Copy X to Y / Copy Y to X: copies the matrix and triggers. A good way to start Y as a variation of X.
  • Clear triggers: for X, Y or both.

Everything is saved with the patch. Patches made with version 2.0 load with their matrix and hits (as 0 / 100 chances) intact.

Interlock

A 16 HP trigger processor that makes parts answer each other. Six triggers come in (A to F) and six go out. Patch Francois Markovian's outputs into it, or Seuperclidean's, or anything else.

The influence grid

The 6 x 6 grid says "when track X fires, track Y's chance on the next step changes by this much", from -100 to +100. The row is the track that fired, and the column is the track that gets pushed. On every step, each track's chance is:

  • 100% if a trigger came in, 0% if not,
  • plus the influences of every track that fired recently,
  • kept between 0 and 100.

So a negative influence can hold back an incoming trigger, and a positive one can add a ghost hit where nothing came in. Influences add up, so two tracks each pushing E by +50 give E a full 100%.

Example (right-click, Load the guide's example):

CellValueEffect
A → B-100B can never play straight after A
A → C+50C is pushed to play after A
C → C-40C damps its own rolls (the diagonal is a track acting on itself)
B → D+60D gets ghost hits after B
D → A-30A is less likely after D

Drag a cell up (green, push) or down (red, hold back). Shift drags finely, and double-click clears a cell. A row's outline flashes when its track fires. The NOW meters under the grid show how much each track is being pushed on the current step.

Timing: incoming triggers are passed on (or held back) the moment they arrive, with no delay. Ghost hits are rolled 2 ms after the clock, so triggers coming from another module (which reach Interlock a sample after the clock) count before the ghosts are decided. Use the same clock for Interlock and the sequencer feeding it.

Right-click: Clear grid, Load the guide's example, Randomise.

Governor

A 22 HP feedback controller. It listens to up to 6 trigger tracks, measures how busy and how changeable they are, and outputs control CVs that push the music back towards targets you set. Patch the CVs into whatever shapes the pattern (Francois Markovian's EVOLVE, Interlock's AMOUNT, Seuperclidean's density, a VCA...) and the system steers itself.

What it measures

Over the last WINDOW clocks (8, 16, 32 or 64, default 16):

  • Density: the share of possible hits that played, i.e. hits / (window x connected tracks).
  • Variety: how different this window is from the window before it, step by step. 0% = an exact repeat, 100% = nothing in common. It needs two full windows of history before it starts measuring.

Only connected trigger inputs count (all six if none are patched). With the poly TRIG input patched, its channels are the tracks. Tracks muted on the poly ACT input drop out of both measurements, so muting the hats in a breakdown doesn't make Governor pile hits onto the other tracks. If every track is muted, the controls hold still.

The poly STATE output carries 1 density, 2 variety (0 to 10 V), 3 density error, 4 variety error (±5 V), 5 density control and 6 variety control (0 to 10 V).

Rewrite

A 28 HP pattern grower. It takes one bar of triggers for each track and rewrites it every few bars: every hit and every rest is swapped for that track's replacement pattern, and the result is folded back into one bar. The parts grow and mutate on their own clocks, so the groove keeps moving without going random.

How it works

  1. Seed. Until you press SEED, triggers pass straight through (the displays show them dimmed). SEED takes the last bar (16 steps, or 8 from the right-click menu) of every track as its starting phrase.
  2. Grow. At a track's rewrite time each hit becomes the HIT BECOMES pattern and each rest the REST BECOMES pattern. AMOUNT is the chance each step is swapped, so growth is uneven.
  3. Fit. The grown phrase is longer than a bar. FIT chooses how it comes back to one bar: WIN keeps a one-bar slice (where, set by WINDOW + CV), SQZ samples the whole thing evenly into one bar.
  4. Remember. The last 16 generations are kept for REWIND.

The default rules (hit → hit rest, rest → rest hit) are the Thue-Morse pattern, which never settles into a plain repeat.

Linking with poly cables

Every module speaks the same three poly cables, colour-coded on the panels:

CableColourChannelsWhat it carries
TRIGorange6 (A to F)Triggers only, so it's safe to patch into any poly drum module
ACTgreen6 (A to F)10 V = playing, 0 V = muted. Starts at Markovian's mute letters
STATEblue6 or 7Each module's inner values as CVs (listed per module above, and in each jack's tooltip). Split them with VCV Split

The basic chain (one clock and reset into every module): Markovian TRIG → Interlock TRIG IN; Interlock TRIG → Rewrite TRIG; Rewrite TRIG → Governor TRIG. Run ACT along the same path. Rewrite's mono outs go to the drums.

Patch ideas

  • Energy per section: Markovian A to F outs → Governor ins. Density CTRL → Markovian EVOLVE CV (make Y the busier snapshot). Automate density TARGET from Live.
  • Self-locking loop: variety VARIED gate → Markovian FREEZE gate. When things get too chaotic it locks into a loop; once the loop is too repetitive (variety falls), the gate drops and it lets go again.
  • Interplay on demand: variety CTRL → Interlock AMOUNT CV, so the tracks start answering each other more when the groove has been static for a while.
  • Grows only when stale: Governor SAME → Rewrite REWRITE NOW, Governor VARIED → Rewrite HOLD. Window 32, variety target about 30%.
  • Breakdown and return: mute the kick on Markovian for 8 bars (Governor stops counting it), and on the bar it returns, hold Rewrite's REWIND button for a second so the drop lands on the bare seed.
  • Movement into sound: Markovian STATE channel 4 (jump size) through Split → a filter or Just Friends' TIME, so big jumps sound different from steady steps.
